# Enrolment Assistant

Run the integrated timetable and Better Auth app from [`Frontend`](Frontend/README.md).
Its home page requires a verified account; login, signup and password recovery share the timetable's design.

The Flask API is in [`Backend`](Backend/README.md). Its guide covers the local environment, DeepSeek Flash, CORS, frontend connection, and automated/live testing.

The folder `Full Frontend Verion V.1` contains the original standalone UI reference. It is not the authenticated app.
